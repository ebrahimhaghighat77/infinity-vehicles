# infinity-vehicles
🚗 Official vehicle repository for Infinity Roleplay server. Includes custom cars, configs, handling, and server-ready vehicle assets.

This repository contains the vehicles used in the Infinity Roleplay server.

Most of these vehicles were originally leaked or publicly available for free on the internet.
However:

All optimization, editing, handling configuration, texture work, and technical improvements have been done entirely by me.

This includes:

✅ Full server-side optimization

✅ Custom handling setup and tuning

✅ File cleanup and restructuring

✅ Texture editing and improvements

✅ Bug fixes and technical adjustments

Any performance improvements, balancing, and preparation for server use are the result of my own work and effort.

Additionally:

The Infinity server owner has no ownership or rights over this repository, its edits, configurations, or the work done on these vehicles.

Before spreading hate or making judgments, please check the commit logs available in the Infinity Discord server to review the development history and contributions.
